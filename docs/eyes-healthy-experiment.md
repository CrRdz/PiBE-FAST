# Eyes 健康受试者技术验证方案

## 研究定位

本实验只验证低帧率虹膜终点测量的可用性、重复性和质量门控，不估计脑卒中诊断
敏感度或特异度。开始招募前须完成伦理审查或机构要求的豁免确认、知情同意和去标识化
方案。`participant_id` 只能使用研究编号。

## 受试者与会话

- 招募健康成年人；预先记录年龄段、惯用矫正眼镜、既往斜视、眼肌麻痹、眼部手术和
  神经系统疾病，但分析文件不得保存姓名或联系方式。
- 样本量应根据主要重复性指标 ICC 的目标置信区间宽度预先计算；在完成计算前，不在
  论文中承诺人数或功效。
- 每人至少完成两个会话；两个会话是估计跨会话差异所需的最小结构。会话间隔在方案中
  预先规定并逐例记录，尽量保持同一设备、摄像头、屏幕和房间。
- 每个条件先做一次；第一次为 `insufficient` 时立即按同一条件重试一次，用于计算首次
  失败率和重试成功率。不得删除失败尝试。

## 条件矩阵

基准条件采用产品预定使用姿势、房间照明、头部静止和本人日常透明矫正眼镜。距离与
照度都记录连续实测值；近/标称/远距离及低/常规/高照度的具体范围，必须由产品预定
使用环境预先规定，论文不在没有设备规范或预实验数据时填写通用数值。条件顺序按参与者
随机化或采用平衡顺序，避免所有人都按相同顺序完成。

| 目的 | 条件 |
|---|---|
| 跨会话重复性 | 两个会话各一次基准条件 |
| 距离稳健性 | 预先规定的近、标称、远距离；记录连续实测距离 |
| 光照稳健性 | 预先规定的低、常规、高照度；记录连续实测照度 |
| 眼镜影响 | 需要矫正者在安全前提下完成本人透明眼镜 on/off；分别报告，不与无眼镜者混合 |
| 头姿影响 | 头部静止；以及故意随左右目标转头的技术对照 |
| 单次与重复 | 从同一个三次重复记录中预先规定使用第一次响应，和使用三次中位数；不另采一套数据 |

光照条件应避免直视强光。摘除矫正眼镜会影响视物者不得执行 off 条件。故意转头条件
用于比较头姿变化对终点测量和数据缺失的影响，不应被解释为疾病模拟；在健康数据估计
质量界限前，不预设一个自动“转头失败”角度。

## 固定采集协议

1. 记录摄像头型号、分辨率、实际 Face Landmarker 推理帧率、屏幕物理宽度、观看距离、
   实测照度、眼镜和头姿条件。
2. 摄像头原始推理坐标保持不镜像；预览是否 CSS 镜像不改变 `eye_camera_mirrored`。
   若视频文件本身已镜像，采集前显式设置该配置并固定整个实验。
3. 使用顺序：自然直视--中--左--中--右--中--右--中--左--中--左--中--右。
4. 左右各重复三次。三次是可计算中位数并容许一次非典型响应的最小重复数；目标保持
   时间和切换后排除时间属于采集设计变量，按实际软件配置写入日志并在所有条件中固定。
5. 每个尝试单独保存 JSONL，或在清单的 `result_index` 指定该文件中的第几个完成结果。
6. 不因结果不理想而删除、覆盖或重新命名记录；所有排除必须给出预先规定的原因。

每次尝试可用去标识化前缀单独启动日志：

```bash
python -m app.main --log-dir data/keypoints \
  --log-prefix P001-S1-baseline-attempt1
```

只有当输入给 Face Landmarker 的原始帧本身已经水平镜像时才增加
`--eye-camera-mirrored`；页面预览的 CSS 镜像不需要该参数。

## 主要技术终点

### 跨会话重复性

对双眼左/右响应、方向不对称、双眼终点不协调和静息偏向代理报告：

- 双向随机效应、绝对一致性、单次测量 ICC(2,1) 及 95% CI；
- 会话间平均绝对差和被试内 CV；
- Bland--Altman 偏差和 95% 一致性界限。

自动脚本计算点估计；论文正式结果的 ICC 置信区间应通过受试者级 bootstrap 或经验证的
统计软件补充。

### 左/中/右终点区分度

分别报告两眼的有符号“中心--左”和“右--中心”分离量、终点顺序正确率，以及按条件
分层的分布。MediaPipe 虹膜位置不得称为真实视线角度。

### 失败与重试

报告首次 `insufficient` 比例、各失败原因分布，以及首次失败后的重试成功率。阳性或
阴性但质量合格的记录均属于“可解释”，不得只把阴性当作成功采集。

### 条件稳健性和头姿控制

按距离、光照和眼镜条件报告测量可用率、有效帧比例、终点 MAD、响应和失败原因。故意
转头与静止头部条件分别报告头姿变化分布、连续终点指标和测量失败率；健康数据尚未形成
并验证界限前，不报告基于固定角度阈值的“检出率”或“错误拒绝率”。

### 单次与三次重复

在同一记录内比较第一次响应与三次中位数的方向正确率、跨会话 ICC、被试内 CV 和
测量可用率。方向正确率只检查位移符号是否与目标方向一致，不使用未经验证的幅度或
SNR 界值。该分析是配对消融，不把三次中表现最好的单次作为“单次结果”。

## 数据清单与分析

复制并填写：

```text
training/manifests/eyes_healthy.example.csv
```

然后运行：

```bash
.venv/bin/python scripts/analyze_eyes_healthy.py \
  --manifest training/manifests/eyes_healthy.csv \
  --output-json training/reports/eyes_healthy.json \
  --output-csv training/reports/eyes_healthy_attempts.csv \
  --output-markdown training/reports/eyes_healthy.md
```

分析脚本输出跨会话点估计、条件分层、失败/重试、头姿控制和单次/三次消融。缺少真实
日志时不得创建或填写论文结果数字。
